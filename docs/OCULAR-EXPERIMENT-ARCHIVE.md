# MORPHOSPACE — 眼・複眼表現の開発記録（採用終了）

> **状態：2026-11-10 仕様廃止・実装撤去。**
> 本記録は、試作の経緯を後から参照できるようにするためのアーカイブです。
> 現行アプリでは**眼球・複眼・眼柄・眼窩・瞼・瞬膜を生成・描画しません**。
> 味と香りのクオリアを抽象的な生命体として鑑賞する、というプロジェクト本来の目的を優先します。

## 試みたもの

1. **眼DNA・交配**：個数0〜4、眼の種類（camera / ocellus / compound / crystal / liquid）、支持（socket / jointed / flexible / retractile）、大きさ、眼柄長、視線速度、独立性、瞼、瞬膜、複眼外形などをDNA化。親DNA由来の交配・変異を実装した。
2. **眼の取り付け・姿勢**：成長中の形状のSDFに接続し、左右対称や複数コピーにも、完成個体全体として指定数の眼を配置する設計。眼球、支持組織、眼杯、可動瞼・瞬膜を独立メッシュで生成。瞳孔・虹彩・光沢、眼球の視線移動、瞬き、眼柄の揺れと収納を試した。
3. **複眼：離散ポリゴン**：当初は眼球上の約56個の六角錐状突起＋微細な表面反射。疎な「棘のある球体」に見える問題が発生。
4. **複眼：連続多角形レンズ**：細分化した正二十面体の双対を用い、162個の五・六角形の浅いレンズに変更。個眼境界の連続性は改善したが、依然として造形が前面に出た。
5. **複眼：シェーダーによる六角バンプ**：球・扁平球に細かい六角格子の凹凸法線を適用。フレネル、スペキュラ、青緑・紫系の擬似構造色を重ねる。モバイル負荷を抑えるため個眼ポリゴンを増やさない方式。
6. **複眼：円形グラデーション干渉（最終試作）**：60°間隔の三角格子点に正規分布状の円形レンズを置き、中心＋6近傍の高さ場の重なりから境界の六角形を自然発生させる。高さ場の解析的勾配でバンプ法線を得る。格子周波数を **8.2 → 16.4（各方向2倍、面密度約4倍）**に変更。構造色とフレネルを併用。

## 採用終了の理由と決定

眼の存在は具体的な動物の「顔」という解釈を強め、MORPHOSPACEが目指す、観察者自身がランダムな構造物に味・香り・生命感を見いだす開かれた造形から離れる可能性がある。作者判断により**眼表現そのものを撤去**する。最終試作の見た目が問題ないかどうかによらない、作品コンセプト上の決定。

### 保全と互換性

- 専用の生成関数、交配DNA処理、眼の動的GPU更新、眼専用シェーダー、眼用回帰テストは現行ソースから除く。
- 過去の保存済み個体・共有リンクが `eyeDNA` プロパティを持っていても、読み込み時は**無視**し、眼を復元しない。既存の保存レコードを破壊する必要はない。
- 「瞬き」などの語が残っても、それが**体表の発光・音響**（emission blink）を指す場合は眼機能とは無関係なので残す。
- このアーカイブは将来の再導入指示ではない。再導入は新たな明示的決定がある場合のみ検討する。

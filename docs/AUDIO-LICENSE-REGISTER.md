## 公開方針
- GitHub Pages の公開配布物に第三者のMP3を含めない。
- 公開用の標準音声はブラウザ内の独自合成音声（素材ファイル不要）。
- 第三者素材は利用者自身が端末から読み込む実験用に限定。ユーザーの権利・ライセンス順守が必要。
- 将来の同梱は、各素材の個別ページ・著作者・ライセンス・公開日・再配布条件を確定した後に判断する。
- 単純な暗号化・分割・ピッチ変更・混合だけで再配布の問題が解消するとは扱わない。

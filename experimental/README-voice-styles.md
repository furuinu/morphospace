# MORPHOSPACE — 保管中の発声スタイル実験

状態: **未使用・本番無効**（2026-10-28、v15.20.0以降）

## アーカイブ

- `voice-styles.js`: v15.19.5時点の5種類の発声スタイル実験コード。オリジナル、グレゴリアン、鯨歌（イルカ・クジラ）、讃美歌風、読経風。
- `../docs/voice-styles-spec.md`: 原理、研究資料、音量・音質調整、制約の記録。
- `../tests/voice-styles.test.cjs`: 実験用の単体テスト。現行の本番HTMLに組み込まれていないことも確認する。

## 本番動作

`../index.html` はオリジナル発声器だけを使用。上記JSは読み込まず、音声スタイル選択UI・状態保存・スタイル切替の呼出しもない。オリジナルの音量、発光・身体運動との連動、残響、動画保存は継続する。

XServerへの公開スクリプトはHTMLを1ファイルだけ同期する。既に設置済みの旧cronが `data-bundled="voice-styles.js"` という文字列を確認するため、本番HTMLには**無害なHTMLコメント**でその識別子を一時的に残してある。コードを読み込む印ではない。

## 将来、外部JSとして再導入する場合

1. 本番側の発声設定UIと選択保存を新たに設計する。
2. `voice-styles.js` を外部スクリプトとして読み込めるようにし、`MorphVoiceStyles.apply` を現行発声エンジンへ明示的に結線する。JSだけ置いても音声は切り替わらない。
3. XServerへの外部ファイル同期（または実装可能な別の配信方式）を整備する。GitHubでデプロイスクリプトを変更するだけでは既に設置済みのXServer cronは更新されない。
4. 5モードの実音声・相対音量・切替復帰・iPhone Safari・録画を確認する。研究資料に記載した実験結果は現行本番の保証ではない。
5. 新しい同期方式へ移行したら、旧cron互換のHTMLコメントを取り除く。

**現時点ではこのアーカイブを配信・実行する必要はない。**
